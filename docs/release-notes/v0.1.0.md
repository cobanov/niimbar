The first release: the NIIMBOT B1 in the macOS menu bar.

- Battery, lid, roll and labels left, read from the printer over USB.
- Text, QR code, Code 128 barcode and image labels, with a dot-for-dot preview.
- Copies, density and label size; the menu bar icon warns when the lid is open, the roll is out or the battery is low.

Install with `brew install --cask cobanov/tap/niimbar`, or open the DMG and drag NiimBar to Applications.

Signed with a Developer ID certificate and notarized by Apple. Requires macOS 14 or later.
